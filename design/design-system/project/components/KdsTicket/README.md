Phiếu bếp/bar trên KDS, chữ lớn để đọc từ xa.

- Rộng `kds-ticket-width`. Đầu phiếu đổi màu theo thời gian chờ: `bg-sla-ok` / `bg-sla-warn` / `bg-sla-late` với chữ `text-sla-*`. Phiếu quá hạn nháy và phát âm báo.
- Số bàn dùng `kds-title`, đồng hồ dùng `kds-timer`, dòng món dùng `kds-body`.
- Nút "Xong món" cao `target-kds` (72px) để bấm khi tay ướt.
- Món bị huỷ hiển thị cảnh báo nổi bật bằng `bg-item-cancelled` / `text-item-cancelled` và yêu cầu bếp xác nhận đã dừng.
