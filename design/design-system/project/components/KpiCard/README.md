Thẻ chỉ số và biểu đồ cột cho web admin và màn hình chủ quán.

- Nền `bg-surface`, viền `border-subtle`, bo `radius-md`, padding `space-400`. Nhãn dùng `admin-label` với `text-secondary`, chỉ số dùng `admin-metric`, chữ số đều.
- Chênh lệch so với kỳ trước là pill `bg-success-subtle` / `bg-danger-subtle`, luôn kèm mũi tên và số, không chỉ màu.
- Biểu đồ dùng `chart-1` … `chart-6`, kèm chú giải hoặc nhãn trực tiếp.
