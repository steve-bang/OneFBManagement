Bàn phím PIN 4–6 số để đăng nhập thiết bị dùng chung và duyệt hành động cần quyền cao hơn (giảm giá vượt ngưỡng, void món, mở két).

- Mỗi phím cao và rộng `pin-key` (80px), cách nhau `space-200`.
- Hộp nằm ở `z-pin-approval`, trên mọi modal, đổ bóng `shadow-overlay`, lớp phủ `bg-scrim`.
- Tiêu đề nói rõ đang duyệt việc gì. Không hiển thị PIN đã nhập, chỉ hiện chấm.
