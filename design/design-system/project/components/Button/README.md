Nút hành động, bốn cỡ theo vùng chạm của thiết bị.

- Nền `bg-action` (hover `bg-action-hover`, nhấn `bg-action-pressed`), chữ `text-on-action`. Nút phụ: nền `bg-surface` với viền `border-control`. Nút nguy hiểm (huỷ, void): nền `feedback-danger`.
- Chiều cao: `target-min` (44) tối thiểu, `target-comfortable` (48) điện thoại, `target-pos` (56) quầy, `target-kds` (72) bếp.
- Nhãn nói đúng việc sẽ xảy ra, kèm số tiền khi liên quan ("Thanh toán 85.000 ₫").
- Focus hiển thị bằng vòng 2px `focus-ring`, cách nút 2px.
